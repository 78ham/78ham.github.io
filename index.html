业余无线电 · 网络对讲

同一套语音网络，接到每一台设备

78HAM 在 NRLLink 上做客户端。手机、电脑、公网手台、ESP32-S3，以及一个留在 Minecraft 里也能说话的模组，走的是同一套 NRL21 语音包。转发服务器、管理后台、协议文档和通联日志也在这个组织下面。

语音走 UDP 60050。管理页面走 HTTPS，实时通话另有 WebSocket。

手里的设备

五套客户端。安装和按键适配以各仓库的说明为准，这个页面不提供安装包。

Android

手机和对讲机 · Kotlin

按住屏幕上的键说话，松开就收听。可以连多台服务器：每台进一个房间，既能说也能听，其他房间可以只听不说。息屏也能启麦，回到桌面后前台服务继续连着。

实体按键目前认和对讲 D12。CW、DTMF、Robot36 慢扫描电视、文字转语音、最长 60 秒录音和尾音都在这个客户端里。Android 6.0 起。

打开仓库

Desktop

Windows 与 Linux · Python

暗色窗口，也可以关掉界面只用命令行。热键默认是 F5。编码用 G.711 A-law 或 Opus，运行时能换麦克风和扬声器，断线会自己重连。

松开按键可以补 DTMF、一段自己的 WAV，或 MDC1200。Wayland 下没有全局热键，用鼠标按住。许可证是 MIT。

打开仓库

ARDPTT

公网手台 · Kotlin

另一套安卓程序，给互联网手持台用。底是黑的，状态用荧光绿，一屏里的字更密。语音默认 Opus，16 kHz，大约 24 kbps，也能退回 G.711。

文本消息只收不发。开机可以自己连上。仓库里的默认服务器写的是 m.nrlptt.com，端口 60050。

打开仓库

ESP32-S3

网络电台固件 · ESP-IDF

目标板是 ESP32-S3。1.77 寸彩屏，I2S 麦克风和功放，六个键管发射、音量和频道。没配过网时自己开热点，手机连上那个热点，用网页把服务器填进去。

热点名字以 78HAM-ESP32- 开头，后面是网卡地址末尾。语音是 Opus。仓库还在早期，接线写在文档里。

打开仓库

Minecraft

Fabric 模组 · Java

人留在游戏里。Left Alt 发射，N 打开面板选服务器和频道，M 静音。收的是 G.711 A-law，8 kHz。画面上有一块小字，显示连接和正在说话的人。

当前对应 Minecraft 26.2。呼号撞车时 SSID 会自动加一。三个键都能在游戏的按键设置里改。

客户端把包送到服务器。服务器、管理页、协议笔记和通联日志是另外四个仓库。NRLLink 原作是 BH4RPN（BG4VKI）。

转发服务器

Go · nrllink

UDP 把语音和信令按房间转发出去。硬件盒子、ESP32、手机和电脑都朝它说话。浏览器看实时通话走 WebSocket，位置可以报到 APRS。

78HAM 在原仓库上继续改。模块名 udphub，Go 1.21 起。许可证是 MIT。

桌面，以及转发服务器

开始一次通联

顺序就这四步。服务器地址用你自己注册的那一台。

  1. 用自己的呼号

    参加业余无线电通联，要有合法执照和有效呼号。软件不能代替这两样。

  2. 账号在上游注册

    安卓客户端登录用 NRL 小程序里的用户名和密码。小程序是上游的 nrllink-mp，不是 78HAM 的仓库。

  3. 选一台设备

    手机用 Android，电脑用 Desktop，公网手台看 ARDPTT，自己做的板子用 ESP32 固件。填进服务器地址再连接。

  4. 进房间再按键

    连上之后选房间。按住 PTT 说话，松开结束。桌面命令行里对应的动作是 join，热键仍是按住说话。
